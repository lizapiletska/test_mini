This is the complete, step-by-step life of your postman robot.

### 1. 🤖 State: BOOTING (The "Wake Up")

This is what happens when you run `main.py`.

* **Power On:** The `PostmanApp` class is initialized. This creates one instance of *every* module in the correct order:
    1.  `RobotController` (hardware connection)
    2.  `RobotState` (tracks `x`, `y`, `heading`)
    3.  `VisualMapper` (creates the map window, gets `RobotState`)
    4.  `MovementController` (the "safe move" function, gets `Controller`, `State`, and `VisualMapper`)
    5.  All other modules: `Detector`, `Planner`, `Mapper`, `Recorder`, `AIOrchestrator`, `SecurityManager`, `MemoryManager`.
    6.  `DeliveryFlow` (gets all the modules it needs for delivery).

* **Connect:** The `app.run()` method calls `controller.connect()`. The robot connects to your Wi-Fi and enters programming mode.

* **Say Hello:** The `boot_sequence` starts. `state_manager.safe_say(BOOT_GREETING)`.
    * **Robot says:** "Hello. I am starting up."

* **Start Map:** `visual_mapper.start()` is called. A **live pop-up window** appears on your computer, showing a 10x10 meter grid with the robot at the center (0, 0) and an arrow for its heading.
    

* **Load Locations:** `main.py` calls `memory.get_all_saved_locations()`. It reads all `profile_*.json` files. For every person with a saved `(x, y)` coordinate, `visual_mapper.load_permanent_locations()` is called.
    * **On the Map:** Blue 'X' markers with names (e.g., "Bob") appear at their saved coordinates.

* **Check Map:** It calls `mapper.load_map_from_file()`.

* **Load or Scan Room:**
    * **If map *does* exist:** `mapper.get_map_data()` sends the list of saved points to `visual_mapper.load_obstacles()`.
        * **On the Map:** The old scan (hollow red circles with distance labels) is drawn onto the map.
    * **If no map *exists*:** `safe_say(prompts.BOOT_START_SCAN)` is called.
        * **Robot says:** "Analyzing room. Please stand clear."
        * `mapper.scan_and_build_map()` begins:
        * **Loop (12 times):**
            1.  `controller.get_infrared_distance()` gets a distance (e.g., 1500mm).
            2.  `robot_state.get_world_coords(1500)` calculates the absolute `(x, y)` of that obstacle based on the robot's current heading.
            3.  `visual_mapper.add_obstacle(x, y, "1500mm")` is called. A **new red circle** appears on the map.
            4.  `movement_controller.move(LEFTWARD, 1)` is called to turn the robot.
        * **Inside `movement_controller.move`:**
            1.  `controller.move(LEFTWARD, 1)` tells the robot to turn.
            2.  `robot_state.move()` updates the internal `self.heading_deg` by -30 degrees.
            3.  `visual_mapper.update_robot_state()` is called. **On the map, the robot's blue arrow rotates** to its new heading.
        * After the loop, the map is saved to `data/maps/main_room_map.json`.

* **Ready:** `safe_say(prompts.BOOT_SYSTEM_READY)`.
    * **Robot says:** "I am now in working mode and ready for commands."

* **Set State:** State is set to `AppMode.WORKING`. `work_loop()` and `delivery_loop()` begin.

---

### 2. 🤖 State: WORKING (The "Listening" Phase)

The robot is at (0, 0), listening. The map window remains open.

* **Listen:** `work_loop()` calls `state_manager.safe_listen()`.
* **User Speaks:** You say: "Robot, I need to send a message to Bob."
* **ASR & AI:** The text is captured. `AIOrchestrator` returns: `{"intent": "SEND_MESSAGE", "recipient_name": "Bob"}`.
* **React:** `work_loop()` sees `SEND_MESSAGE`.

---

### 3. 🤖 State: COMPOSING (The "Conversation")

The robot gathers the message details. **The map window is still live but unchanging.**

* **Set State:** `main.py` sets state to `AppMode.COMPOSING`.
* **Start History:** `memory.start_conversation_log()` is called.
* **Conversation Flow:** The robot and user have their multi-step conversation (ask for message, sender, recipient, password).
* **Listen (Loop 6):** You say: "Go 20 steps forward and then 10 steps to the right."
* **AI Analyzes (Loop 6):** Returns `{"intent": "PROVIDE_ADDRESS", "address_text": "Go 20 steps forward and then 10 steps to the right"}`.
* **Job Complete:** The `ConversationFlow` saves the job.
* **Finalize History:** `memory.finalize_conversation_log(45192)` saves the *composing* part of the conversation to `data/messages/log_45192.json`.
* **Robot says:** "Your message is saved. The message ID is 45192."
* **Queue Job:** The job is put in the `delivery_queue`.
* **Set State:** State is set back to `AppMode.WORKING`.

---

### 4. 🤖 State: SENDING (The "Delivery")

The `delivery_loop()` has a job. **The map window will now update with the robot's movement.**

* **Set State:** `delivery_loop()` sets state to `AppMode.SENDING`.
* **Get Route:** `delivery_loop()` calls `self.delivery_flow.get_route_for_job(job)`.
    * `memory.get_known_route_for_recipient("Bob")` checks the profile. It finds nothing (or you said "no" to using the saved route).
    * `planner.parse_address_to_route()` parses the `address_text`.
    * It returns the `RoutePlan`: `[(MoveRobotDirection.FORWARD, 20), (MoveRobotDirection.RIGHTWARD, 10)]`.
* **Execute:** `delivery_flow.execute_delivery_flow` is called.
    * `recorder.save_route_for_return()` saves the plan.
    * `_safe_execute_route` begins. `isWalking` is set to `True`.
* **Move (Step 1):**
    * `movement_controller.move(MoveRobotDirection.FORWARD, 20)` is called.
    * `controller.move(FORWARD, 20)` tells the robot to move.
    * `robot_state._convert_steps_to_meters(20)` returns `0.48` meters.
    * `robot_state.move()` updates its internal state. `self.x_m` = 0, `self.y_m` = 0.48.
    * `visual_mapper.update_robot_state()` is called. **On the map, the robot dot moves** to its new `(0, 0.48)` coordinate.
* **Move (Step 2):**
    * `movement_controller.move(MoveRobotDirection.RIGHTWARD, 10)` is called.
    * `controller.move(RIGHTWARD, 10)` tells the robot to turn.
    * `robot_state.move()` updates its state. `10 steps * 30 deg/step = 300` degrees. The new heading is `(0 + 300) % 360 = 300` degrees.
    * `visual_mapper.update_robot_state()` is called. **On the map, the robot's arrow rotates** to 300 degrees.
* **Arrive:** The route is finished. `isWalking` is set to `False`.

---

### 5. 🤖 State: RECEIVING (At the Destination)

The robot is at Bob's location, `(0, 0.48)` and facing 300 degrees.

* **Set State:** `delivery_flow` sets state to `AppMode.RECEIVING`.
* **Load History:** `memory.load_conversation_log(45192)` loads the composing log.
* **Interact:** The robot "knocks," confirms identity ("Are you Bob?"), announces the sender ("Message from Alice:"), and verifies the password ("Oranges").
* **Deliver Message:**
    * **Robot says:** "Message from Alice: Tell him lunch is at 7 in the cafeteria."
* **Save Route & Location:** This is the new, combined step.
    1.  `robot_state.get_state()` is called, returning `(0.48, 0, 300)`.
    2.  `memory.save_route_for_recipient("Bob", route_plan, 0.48, 0, 300)` is called. The `profile_bob.json` file is created, now containing the route *and* the final coordinates `{"location": {"x": 0.48, "y": 0.0, "heading": 300.0}}`.
    3.  `visual_mapper.add_permanent_location(0.48, 0, "Bob")` is called.
    4.  **On the map, a new blue 'X' labeled "Bob" appears** at the robot's current location.
* **Confirm Save:**
    * **Robot says:** "I have saved this new location for Bob."
* **Finalize History:** `memory.finalize_conversation_log(45192)` saves the *complete* log (composing + delivery) to the file.
* `execute_delivery_flow` returns `True`.

---

### 6. 🤖 State: RETURNING (Going Home)

The robot must now return to `(0, 0)`.

* **Set State:** `delivery_loop` sets state to `AppMode.RETURNING`.
* **Get Return Plan:** `delivery_loop` calls `delivery_flow.go_home()`, which calls `recorder.get_return_route()`.
* **Reverse Route (Smart):** The `RouteRecorder` takes the original plan `[(FORWARD, 20), (RIGHTWARD, 10)]` and reverses it:
    1.  Reverse `(RIGHTWARD, 10)` -> `(LEFTWARD, 10)`
    2.  Reverse `(FORWARD, 20)` -> `(LEFTWARD, 6)` (180° turn), `(FORWARD, 20)` (move), `(LEFTWARD, 6)` (180° turn).
    * **Final Plan:** `[(LEFTWARD, 10), (LEFTWARD, 6), (FORWARD, 20), (LEFTWARD, 6)]`
* **Announce:**
    * **Robot says:** "Delivery complete. Returning to my starting point."
* **Execute Return:** `delivery_flow.go_home()` executes the return plan, calling `movement_controller.move` for each of the 4 steps.
    * **On the map, the robot's dot and arrow are updated live** as it turns, turns again, moves 48cm, and turns a final time, arriving back at `(0, 0)`.
* **Arrive Home:** `go_home()` finishes.
* **Set State:** `delivery_loop()` sets state back to `AppMode.WORKING`.
* **Robot says:** "Does anyone else have a message to send?"
